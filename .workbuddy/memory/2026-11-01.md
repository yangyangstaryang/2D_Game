# 2026-11-01

## 修复开局黑屏：Fade 改为纯代码实现

**问题**：点 Play 动画状态机直接播 FadeOut，播完卡住全黑。

**根因**（两处，都在 Animator 方案本身）：
1. `Animations/Misc/FadeAnim.controller` 的 `m_AnimatorParameters: []` —— 没有 `FadeIn` 这个 bool 参数，`animator.SetBool("FadeIn", ...)` 直接报 "Parameter does not exist"
2. 两个状态之间没有任何 Transition（`m_Transitions: []`、`m_AnyStateTransitions: []`），进了默认状态永远出不来；动画片段 `m_LoopTime: 0`，播完停在最后一帧（FadeOut 末帧 alpha=1）

**方案**：抛弃 Animator / 动画片段，`Scripts/Fade.cs` 重写为纯代码遮罩。

- `Fade.Instance` 惰性创建（场景里没挂物体也能用），自动建 Canvas(Overlay, sortingOrder=32000) + 全屏 Image，铺满屏、raycastTarget=false、开局 alpha=0
- 复用已有 Canvas/Image（若手工搭过），同时禁用残留 Animator、把残留 Image alpha 清 0
- API：`FadeOut(dur)` / `FadeIn(dur)` 返回 Coroutine 可 yield 等待；`LoadSceneWithFade(scene, onLoaded)` 一步完成淡出→切场景→回调→淡入，自带 `loading` 防重入；`SetAlphaImmediate(a)`
- 用 `Time.unscaledDeltaTime`，暂停/慢放也能正常淡

**调用点改动**：
- `GameManager.Update` 的 J/K 切场景 → `Fade.Instance.LoadSceneWithFade(...)`
- `GameManager.Start` 开头预热 `Fade.Instance.SetAlphaImmediate(0f)`
- `GameManager.WaitToReload` → `yield return FadeOut()` → LoadScene → `yield return null` → ReSet → `yield return FadeIn()`
- `PlayerController.LoadTargetScene` → `Fade.Instance.LoadSceneWithFade(targetScene)`

**待用户确认**：Unity 里手搭的 Fade 物体（带 Animator 的，未保存到磁盘）若存在需删除，新旧两套不能并存。
