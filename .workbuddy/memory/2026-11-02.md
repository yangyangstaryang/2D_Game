## 存档系统重构（2D Game / Unity）

**背景**：用户误删场景 UI（菜单面板未提交，git 无法恢复），执行了 `git restore .`，Unity 内存场景未刷新导致误判。已在桌面 `Desktop/Scripts` 找到误删前的脚本备份作参考。

**已做的事**
- `PlayerController.cs:103` 改为 `Menu.Instance != null` 判空，解决无菜单物体时的空引用。
- 新增 `PlayerController.RestoreFromSave(int hp, Vector3 pos)`：恢复位置/血量/精力，清死亡、传送、击退、冲刺状态，朝向下。
- `SaveDataSO.cs`：新增 `sceneName`、`List<SlotSaveData> slots`（index/itemID/amount），`Save()` 收集场景名+位置+血量+背包，`Load()` 调 RestoreFromSave 并导入背包。
- `SaveSysten.cs`：去掉 BinaryFormatter 双层包装，改纯 JSON 文本写 `persistentDataPath/SaveData/SaveData.txt`；`PathOf()` 处理前导斜杠；读档解析失败容错；新增静态 `InventorySnapshot` 做跨场景背包快照。
- `Menu.cs`：沿用原 SaveData/LoadData 命名；读档改为协程 `FadeOut → LoadScene → yield null → saveData.Load() → FadeIn`，协程托管在 `Fade.Instance`（DontDestroyOnLoad）避免切场景中断。关键修复点：原来 LoadScene 后立刻 Load()，会被新场景 `Gate.Start()` 覆盖位置。
- `Inventory/Slot.cs`：加 `Amount`、`RestoreItem`、`ClearItem`，增删物品时 `SyncSnapshot()`。
- `Inventory/InventorySystem.cs`：加 `itemDatabase`(List<BaseItemDataSO>)、`ExportSlots/ImportSlots/SyncSnapshot/FindData`，Awake 时用快照补回背包；导入时重挂消耗品 useAction。
