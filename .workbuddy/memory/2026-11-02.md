## 中文缺字修复（TMP 显示方块 □）

- 现象：`The character with Unicode value \u620F was not found in the [LiberationSans SDF] font asset` —— TMP 默认字体无汉字。
- 方案：把 `C:/Windows/Fonts/Noto Sans SC (TrueType).otf`（OFL 协议可分发）复制为 `Assets/Resources/Fonts/NotoSansSC.otf`（8.1MB）。
- `Assets/Scripts/ChineseFont.cs`：`ChineseFont.Get()` 先 `Resources.Load<TMP_FontAsset>("Fonts/NotoSansSC SDF")`，没有再运行时 `TMP_FontAsset.CreateFontAsset(font, 90, 9, GlyphRenderMode.SDFAA, 1024,1024, Dynamic, true)` 兜底；`Apply(TMP_Text)` 直接赋值。
- `Assets/Editor/ChineseFontBuilder.cs`：菜单 `Tools → 生成中文字体资源`，生成 `Resources/Fonts/NotoSansSC SDF.asset`（Dynamic 图集）并把 atlas/material 存为子资源，同时写入 TMP Settings 的 `m_fallbackFontAssets` 作为全局后备字体。
- 已验证 TMP 3.0.7 API 签名：`CreateFontAsset(Font, int, int, GlyphRenderMode, int, int, AtlasPopulationMode, bool)`；`TMP_Settings` 字段名 `m_fallbackFontAssets`；`AtlasPopulationMode` 在 TMPro 命名空间，`GlyphRenderMode` 在 UnityEngine.TextCore.LowLevel（易漏 using）。
